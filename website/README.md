# whestbench docs site

Next.js + Fumadocs static site for whestbench, deployed to GitHub Pages.

- `make docs-serve` (from repo root) — local dev server
- `make docs-build` — generate API/CLI + federate starter-kit + build + checks
- API/CLI pages: generated by `scripts/generate_docs.py` (gitignored)
- Participant Guide: federated from `whest-starterkit` at the pin in `starterkit.lock.json` (gitignored)
- `llms.txt` / `llms-full.txt`: generated post-build by `scripts/generate-llmstxt.mjs`
